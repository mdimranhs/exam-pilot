# ExamPilot ✈️

AI-powered exam preparation platform.

> Learn. Practice. Write. Improve.

## Overview

ExamPilot is a React Native + Expo application focused on competitive
exam preparation.

The initial focus is Bangladesh government-job preparation, beginning with
Assistant Programmer and NTRCA.

## Core Feature

The main differentiator is subjective answer practice.

Users can:

1. Learn a topic
2. Practice questions
3. Write subjective answers
4. Get AI-powered evaluation
5. Improve their answer
6. Rewrite it
7. Track their improvement

## Tech Stack

- React Native
- Expo
- TypeScript
- Expo Router
- Zustand
- TanStack Query
- Supabase
- PostgreSQL
- NativeWind
- Next.js
- AI API
